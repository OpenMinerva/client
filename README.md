# PrismLens

Connect with PrismLens on [Discord](https://discord.gg/PnAx8KDn)!

### What is PrismLens?
PrismLens is a VR platform with a focus on education. PrismLens is built upon Godot 4.X and is open source.

### Who is PrismLens for?
The target audience is for educators, students, and others with a desire to learn. However, PrismLens can be used for much more than education. PrismLens can be used to host local get-togethers, or private events.
