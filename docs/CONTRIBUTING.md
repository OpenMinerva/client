# Introduction

PrismLens is a project with a primary focus of creating interactive and immersive educational experiences. When contributing, please keep this in mind! PrismLens is not built to be a traditional social space like that of [VRChat](https://vrchat.com/), or [Resonite](https://resonite.com/). While this is an educational focused application, features, bugfixes, and suggestions that make socializing more enjoyable are welcomed.

### Guidelines
When interacting with this repository, you are expected to adhere to the project guidelines. There currently is not a document detailing what is or is not permitted when interacting with the community. Until such a document is produced, please adhere to the golden rule. Be kind to each other. 

If you prove to be more trouble than you are worth putting up with, you will be forcibly removed from the project.

### Good Contributions
Currently, as this project is very young, major contributions are not actively being sought out. This is due to project standards just not existing yet. 

For the time being, please only submit bug fixes.

This project is split into these major branches:
- master 
- beta 
- alpha

The `master` branch is the stable release of the application. As a contributor, you should never directly commit into `master`. Master is typically pushed into from the branch `beta`. `beta` is pushed into from `alpha`. When submitting a brand new feature, you should submit it targeting the `alpha` branch. Should the feature pass testing with minimal bugs, it can be merged into `beta`. `beta` is a more long-term testing that should remain stable for daily use. 

### Bad Contributions
Currently, contributions with entirely new features are not being sought out. If you desire a feature, please make an [Issue](https://github.com/PrismLens/client/issues). This will change in the future as this project matures. You are free to make feature requests, but please keep in mind as the structure of this project is still thin, your feature pull request may be rejected for seemingly arbitrary reasons.

Please do not make support requests in the issues area. If you need support, please find the support/help channel in the [Discord](https://discord.gg/PnAx8KDn).

# Ground Rules

Responsibilities:
* Ensure cross-platform compatibility for every change that's accepted. Windows and Linux.
* Create issues for any major changes and enhancements that you wish to make. Discuss things transparently and get community feedback.
* Don't add any classes to the codebase unless absolutely needed. Err on the side of using functions.
* Keep feature pull requests as small as possible, preferably one new feature per pull request.

# Your First Contribution
If you want to get started with contributing to the code base, the easiest way to start is to look at the `good-first-issue` label in the [Issue](https://github.com/PrismLens/client/issues) area. These issues should help you get familiar with the code base. 

# Reporting a bug
If you find a security vulnerability, do NOT open an issue. Join the Discord and send a private message to `Armored Dragon`. Make sure you are messaging the correct one, look for the "Developer" role! Please keep in mind this will change in the future.

In order to determine whether you are dealing with a security issue, ask yourself these two questions:
* Can I access something that's not mine, or something I shouldn't have access to?
* Can I disable something for other people?

If the answer to either of those two questions are "yes", then you're probably dealing with a security issue. Note that even if you answer "no" to both questions, you may still be dealing with a security issue, so if you're unsure, just message `Armored Dragon`.

### Template.
When filing an issue, make sure to answer these five questions:

1. What version are you using?
2. What operating system are you using?
3. What did you do?
4. What did you expect to see?
5. What did you see instead?
